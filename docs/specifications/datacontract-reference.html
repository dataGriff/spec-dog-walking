Fundamentals

Basic information about the data contract

Name
Dog Walking Data Contract
Version
1.0.0
Status
active
Purpose
Defines the structure and quality expectations for data published by the Dog Walking domain via domain events. This contract is the authoritative historical integration point for downstream consumers (reporting, analytics, downstream sync). Per SUITE-DESIGN §4.5 every record carries the full state of its affected entity at the moment of the event — the contract is the audit-grade historic record.
Usage
Consume this contract to understand the schema of records emitted on the `dogwalking.*` event channels. Use it as the basis for pipelines, analytics, and reporting on the walker's business.
Limitations
Covers the event payload only (data envelope). CloudEvents metadata fields (specversion, type, source, id, time, datacontenttype) are documented in `asyncapi.yaml` and not repeated here.
